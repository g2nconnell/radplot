Enter a mathematical expression for y in terms of x (or theta if using polar coordinates). Use standard mathematical functions and operators. For example:

  • sqrt(10 / (cos(2 * theta)))
  • sin(x) + cos(x)
  • exp(-x^2)

Use explicit multiplication (e.g., 2 * x instead of 2x).

Ensure that your expression is valid and does not contain any syntax errors.

Enter a list of specific x-values (or theta values for polar plots) that you want to see in the results table. Separate each value with a comma. For example:

  • -3, -2, -1, 0, 1, 2, 3
  • 0, 45, 90, 135, 180

If you leave this field empty, the table will display all calculated values based on the x-axis range and tick count.

Advanced Polar Plot Settings

Enter a list of specific theta values (in degrees) that you want to see in the results table. Separate each value with a comma. For example:
